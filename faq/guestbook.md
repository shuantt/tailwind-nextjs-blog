# Guestbook 與聯絡表單

`/guestbook` 提供免登入的公開留言，原有文章留言保留。

- 留言需經站主審核，既有私密訊息不會轉為公開。
- 網址或 Email 至少填寫一項；網址會公開，Email 不會顯示在留言板。
- 送出前須閱讀隱私權條款、主動勾選同意並完成安全驗證。
- 站主可管理留言與回覆；郵件通知失敗不影響已收到的訊息。
- 資料使用及刪除申請方式請見網站的 `/privacy` 頁面。

## 開發檢查

`yarn check` 檢查程式碼與文章內容，`yarn guestbook:test` 執行隔離測試，
`yarn build` 確認建置。隔離測試不會連接正式服務或寄送郵件。

本 repository 公開，不存放私人資料、憑證或實際環境設定。
隱私權頁面移除的技術細節不另外保存在文件中。
