## 久違的寫文章

再次更新部落格居然是兩年後的 2026，以時間點來說實在好荒謬。

其實一直都有很多想做的計劃，但很多事總是沒做完或者沒達到自己的目標，往往覺得不夠格寫出來，也沒人會想看這些。

最近和朋友做了 Life Coach，也嘗試和 AI 做了 Coaching ，讓我的想法稍微改變了：反正也沒人在看，那我到底在害怕什麼？為什麼要糾結寫得好不好呢？**想到什麼寫什麼就好了**。

## 自架部落格的缺點：功能得自己慢慢加

我很喜歡我的部落格，但這個框架最讓我困擾的事情是**「發文要推 git 」**這件事。

卡在我會想寫文章的時候大概就是**「通勤無事可做的時候」**，但這時在手機上要編輯和確認文章樣式就偏麻煩。凸顯出自架部落格的缺點——**很多功能不完善**。但因為真的很喜歡現在的部落格設計（甚至今天很認真的改了個很酷的 Hero！），縱使沒有大平台完整的功能和流量，還是捨不得棄用這邊。

如今有萬能的 AI，要找到不能解的事情還真不容易。一下就提供我好幾個解決辦法，最後是透過 GitHub 設定好 ++[Pages CMS](https://pagescms.org/)++ ，問題一下就解決了，當然撰寫還要再透過第三方網站還是沒那麼直覺就是。

++[Pages CMS](https://pagescms.org/)++ 免費開源，裝個 GitHub App，專案稍微設定，就能用手機瀏覽器登入 [app.pagescms.org](http://app.pagescms.org) 開啟新增文章介面，可使用類 Notion Command 的編輯器撰寫文章，也能直接看 Source 寫 Markdown。

中間除了對介面不熟外，還卡了一個小雷：因為我最近部落格改版時新增文章的「Category 」欄位，但 Pages CMS 我是更久之前就設定好的，所以撰寫時一時選不到分類，存下去網站顯示上會直接出問題，但總體而言安裝和寫作都很容易。

## 想再試著開始寫文章

更多技術類或設定教學大概就不寫了，現在寫這篇，其實是想做手機撰寫的測試文，能發出來就代表流程有通，這個世代凡事還是問 AI 更有效率。

最近應該會密集的丟出好幾篇貼文。想到自己在 2026 才開始回來寫部落格就覺得有點蠢。常常在在思考現在的我，到底有什麼東西是值得寫出來、值得被被看見的？

寫部落格的初衷是想寫技術文章，但如今技術文存在的意義大概只剩幫助自己鞏固記憶的用途，甚至在 AI 協作下，我越來越常追求結果而鮮少追求技術。但相反來說，既然現在不用再擔心技術文章的好壞或專業度，那就更可以放飛自我，隨心所欲的亂寫了對吧🙂‍↕️
