# SHUANTT｜Shuan Tseng 的個人部落格

記錄產品開發、學習成長與生活。這裡是 [Shuan Tseng（shuantt）](https://github.com/shuantt) 個人部落格的原始碼，也保留了網站從模板逐步調整成個人創作空間的過程。

**[閱讀部落格 ↗](https://blog.shuantt.com/)** · [所有文章](https://blog.shuantt.com/posts) · [作品集](https://blog.shuantt.com/projects) · [關於我](https://blog.shuantt.com/about)

## 專案出處

本站以 [Timothy Lin](https://github.com/timlrx) 的 [Tailwind Next.js Starter Blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) 為基礎，沿用 Next.js、Tailwind CSS 與 MDX 的部落格架構，再依個人寫作、內容整理與作品展示需求持續客製。

本站沿用的框架功能包含：

- **MDX 內容管理**：以 Markdown 撰寫文章，支援自訂元件與圖片。
- **標籤與文章列表**：各標籤有獨立頁面，提供文章列表版型與分頁瀏覽。
- **文章版型與作者資料**：提供多種文章版型，支援作者介紹與多作者設定。
- **程式碼與進階排版**：支援程式碼語法高亮、行號、數學公式、引用文獻與提示區塊。
- **亮暗主題與響應式版面**：提供主題切換及不同螢幕尺寸的閱讀基礎。
- **圖片與字型最佳化**：使用 Next.js 的圖片與字型處理功能。
- **搜尋與留言**：整合 KBar 站內搜尋與 Giscus 留言。
- **作品展示**：提供 Projects 頁面與作品卡片基礎。
- **SEO 與流量分析**：提供 sitemap、頁面 metadata 與分析服務整合，本站使用 Google Analytics。

在這些基礎上，本站新增分類層級，與原有標籤組成雙層內容架構，並客製首頁與作品展示。

## 部落格導覽

- [Home](https://blog.shuantt.com/)：個人介紹、近況與近期文章。
- [Posts](https://blog.shuantt.com/posts)：開發、學習與生活文章，搭配分類與[標籤](https://blog.shuantt.com/tags)瀏覽。
- [Projects](https://blog.shuantt.com/projects)：作品介紹、技術細項，以及 Demo、API Docs 或 Dev Log。

## 個人調整

- **整合 Pages CMS**：方便手機編輯文章、管理圖片與預覽發布內容。
- **視覺與互動**：調整網站識別、首頁、資訊卡片、配色與動畫，並隨內容需求持續改版。
- **作品展示**：調整 Projects 版面與作品卡片樣式，重新安排圖片、專案介紹、技術資訊及相關連結。
- **文章閱讀**：在文章版型加入桌機側邊目錄（TOC）與閱讀時間，方便掌握文章結構與跳轉段落。
- **搜尋與分享**：客製頁面標題、摘要、文章結構化資料與社群分享資訊。
- **網址與索引**：統一文章、sitemap 與站內搜尋的路徑，保留舊址轉址，並依內容數量調整分類與標籤頁索引。
